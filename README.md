# The Book Shelf - Online Book Store

A full-stack online bookstore built using the MERN stack, featuring user authentication, book browsing, search and filtering, cart management, checkout, order tracking, and admin functionality.

## Features

- User registration and JWT-based authentication
- Browse books and view detailed information
- Search and filter books
- Add and remove books from cart
- Checkout and order management
- View order history
- Admin book management
- Admin order status management
- Responsive React interface
- RESTful backend APIs
- MongoDB Atlas database integration

## Tech Stack

### Frontend
- React.js
- React Router
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- REST APIs

### Deployment
- Frontend: Render
- Backend: Render
- Database: MongoDB Atlas
